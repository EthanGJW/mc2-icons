# MC2 Icons

Public image assets used by MC2/Mihomo proxy-group icons. No private configuration or credentials are stored here.

## Assets

- `iptv.png` — 当前长期主图标（PNG）。
- `iptv-v2.png` — MC2 兼容性测试版：256×256、RGB、白色实体背景、图案约占画布 72%。
- `iptv.jpg` — 旧版回退图标。
- 固定 Raw 地址（当前主图标）：`https://raw.githubusercontent.com/EthanGJW/mc2-icons/main/iptv.png`
- 测试 Raw 地址：`https://raw.githubusercontent.com/EthanGJW/mc2-icons/main/iptv-v2.png`

保持文件名和路径稳定；以后如需替换图标，只更新同名资源，避免修改 MC2 YAML 中的图标 URL。

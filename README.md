# MC2 Icons

Public image assets used by MC2/Mihomo proxy-group icons. No private configuration or credentials are stored here.

## Assets

- `iptv.png` — IPTV直播代理组主图标（128×128 PNG，优先用于 MC2）。
- 固定 Raw 地址：`https://raw.githubusercontent.com/EthanGJW/mc2-icons/main/iptv.png`
- `iptv.jpg` — 旧版兼容/回退资源，当前不作为 YAML 主地址。

保持主图标文件名和路径稳定；以后如需替换图标，只更新同名 `iptv.png`，避免修改 MC2 YAML 中的图标 URL。
